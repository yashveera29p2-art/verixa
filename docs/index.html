Install in 4 taps

  1. Tap Download Verixa above. If Chrome asks, tap Download anyway.
  2. When it reaches 100%, tap Open in the bar at the bottom of Chrome, or tap the download notification. (You can also find Verixa.apk in Files → Downloads.)
  3. If Android says installs from this source aren’t allowed, tap Settings, turn on Allow from this source, and go back. Then tap Install.
  4. Tap Open. Verixa is now on your home screen and in your app list.

If Play Protect says the app is unknown, tap More details → Install anyway. Verixa isn’t on the Play Store yet, so Android shows this for any app installed from a link.

Already have Verixa? Download again and tap Update. Your account and resumes stay.

iPhone isn’t supported. Apple doesn’t allow installing apps from a link.

Verixa is an academic NLP project. Resume files are processed in memory and never stored. · All versions
